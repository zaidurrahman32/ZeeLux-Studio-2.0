ZEELUX STUDIO — IMAGE FOLDERS
=============================

1) PROFILE PHOTO (hero section)
   Add your professional portrait here with this exact path:

       public/images/profile.jpg

   Recommended: ~900×1100px, JPG or PNG (you can also name it
   profile.png — then update `site.profileImage` in
   src/data/content.js to '/images/profile.png').

   Until this file exists, the site shows a styled "ZR" monogram
   placeholder automatically.

2) PROJECT IMAGES
   Put project screenshots in:

       public/images/projects/

   Then reference them in src/data/content.js, e.g.:

       image: '/images/projects/lumen-store.jpg',

   Recommended: 16:9 ratio, around 1600×900px, compressed JPG/WebP.
